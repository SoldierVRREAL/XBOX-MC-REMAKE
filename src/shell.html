Play Online

Photon needs your own free Realtime AppId and the Photon JavaScript SDK (put photon.min.js beside this page, or give its URL). Hosted pages work; this preview blocks outside connections, so use "Same browser, other tabs" here. The first player in a room hosts: it runs the bots, chests and round timer.

Resource Packs

Load Java Edition resource packs (.zip) or a Minecraft client .jar you own. They're read on this device only and remembered in this browser. Packs stack: load a full texture source (for example the 1.21 client jar or Programmer Art) first, then the Legacy Console pack for its panorama, bat and sounds.
