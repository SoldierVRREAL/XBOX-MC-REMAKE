Play Online

Everyone types the same room code and presses Connect. The first player in a room hosts: it runs the bots, chests and round timer. If you run the game's own server (node server/server.js), players on it connect to it automatically, or type its address above. Without one, the game uses free public relays, so pick an unusual room code.

Resource Packs

Load Java Edition resource packs (.zip) or a Minecraft client .jar you own. They're read on this device only and remembered in this browser. Packs stack: load a full texture source (for example the 1.21 client jar or Programmer Art) first, then the Legacy Console pack for its panorama, bat and sounds.
